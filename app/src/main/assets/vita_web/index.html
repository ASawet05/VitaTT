    4. 

  4. Saklama yeri. Yerel depolama ile kullanımda kayıtlarınız yalnızca bu cihazın tarayıcı/uygulama hafızasında tutulur. Bulut (Firebase) ile giriş yaparsanız yedekleme amacıyla kayıtlarınız Cloud Firestore'a da yazılır.
